# 起動復帰機能の検証範囲

## 2026-09-26の候補

通常の`0x21`起動では復帰命令を送りません。ブート`0x54`だけが応答する場合、確認待ちを端末へ保存してから`0x77`を一度送ります。以後は最大約2秒・10回の`0x21`確認と設定読戻しで復帰を判定します。確認待ちが残る本体再起動では`0x54`を再確認せず、命令を再送しません。未送信在庫は保持します。

- 実際の復帰判定関数を使う合成試験で、正常時の無送信、記録保存の先行、単発送信、時間・回数上限、再起動後の再送禁止、設定不一致、保存失敗、確認後だけの記録解除を確認しました。IR消灯の初期化、既存FIFO・保存応答・再送表示の試験も成功しました。
- 同一ファームウェアソースでPlatformIOのAtomS3・StickS3送信版をビルドしました。公開用の配置後にソース一致、Arduino版との同期、配布ZIPの内容と認証情報除外、native合成試験を再確認しました。
- Arduino CLIではStickS3 / M5Stack 3.3.7のC++コンパイル・リンクを確認しました。ライブラリはM5Unified 0.2.22、M5GFX 0.2.29、M5UnitQRCode 1.0.1、ArduinoJson 7.2.1です。Mac上で同梱ctagsが実行できないため、自動プロトタイプ生成だけを無処理にした限定検証です。通常のArduino IDE操作全体やM5UnitQRCode 1.0.0の今回の再検証とは扱いません。
- 両機種の表示シミュレーターで各29画面を生成し、`READER RESUME`・`RECOVERY HOLD`を目視確認しました。キャプチャのコード・電池残量は合成例です。
- PDF / 編集用PPTXは23ページです。起動付録を更新し、元の22ページと著作権表示を保持しました。本文一致と付録の描画を確認しました。

ブート復帰は実機未検証です。通常起動や過去の実送信の成功を、今回の`0x77`による実復帰・新規スキャン・Scans保存の成功とは扱いません。本件のUnit起動時の不調とスキャン中の異常は別であり、電源原因の確定や再発防止の実証も含みません。

### 新候補のStickS3実機確認

- 接続機のチップ・アプリ領域・NVS構成を確認し、確認済み旧アプリとの一致を照合してから、新候補のアプリ領域だけを書き込みました。書込みハッシュ検証に成功し、NVSと未送信在庫を全消去していません。書込み前後の未送信キューは0件でした。
- 起動ログでIR出力LOW、SDA=9/SCL=10、通常アドレス0x21の応答、Unitアプリ版3、手動モード1、TRIG解除状態1を確認しました。約1.95秒でリーダー初期化が完了し、READYとWi-Fi接続まで進みました。
- 書込み後25秒の観測と、追加の通常再起動1回・18秒の観測で、USBの予期しない再切断を認めませんでした。旧単一イベント用キーのNOT_FOUNDは未作成を示す既存の取込み確認で、キュー復元成功を確認しています。Wi-Fi初期化のログの後も接続成功しています。
- いずれも通常モードで起動したため、0x77は送られていません。実際のブートモードからの復帰、新規TRIG読取り・Google保存、冷間起動の成功率、瞬間的な電圧低下は今回未確認です。ブートモードの強制誘発やリセット連打はしていません。AtomS3は今回ビルド・画面・合成試験の対象で、接続が見つからなかったため書き込んでいません。

## StickS3表示の視認性改訂 2026-10-20

- 左上のWi-Fi状態を弧形アイコンへ変更し、オンラインは緑、オフラインは灰色と斜線で示す。右上の電池は残量に比例して左から全体を塗り、中央の残量％を大きくした。取得できないときは塗らずに`--%`と表示する。状態名、未送信数、説明文もStickS3の135×240pxへ合わせて配置した。AtomS3の分岐は維持した。
- 本番の`InventoryDisplay.h`で両機種のSDLシミュレーターをビルドし、各29状態を描画した。StickS3の29画像は承認済み最終案と画素単位で一致し、AtomS3の29画像は変更前と画素単位で一致した。電池の0%、100%、取得不可、Wi-Fi状態、未送信0/9/10/16件、再送進捗と長いコードを含む。15%、30%、50%は設計比較時の合成入力で確認し、実測値ではない。
- PlatformIOのAtomS3・StickS3送信版ビルド、Arduino版ソース同期、既存の保存・再送・読取器状態のnative合成試験が成功した。READMEの画面例と説明を更新し、PDF/PPTXの22ページの3画面を新しい実描画画像へ差し替えた。PPTXは画像3点以外、PDFは22ページ以外の描画を維持した。
- 実機画面の視距離・輝度での読みやすさ、実読取り、Google Sheetsへの新規保存、実際のスキャン間隔はこのシミュレーターとビルドでは確認できない。
